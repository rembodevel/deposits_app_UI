# Deposits App UI

Мобильное приложение на Flutter для учета банковских вкладов.

## Возможности

- Добавление вклада
- Добавление в избранное
- Просмотр всех вкладов
- Просмотр избранных вкладов
- Удаление вклада свайпом
- Отмена удаления

## Технологии

- Flutter
- Dart
- StatefulWidget / setState
- TabBar / TabBarView
- ListView
- Dismissible
- TextField
- ModalBottomSheet
- SnackBar
- FloatingActionButton
